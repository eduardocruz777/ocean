# 🚢 Oceanis Cruises - Landing Page de Alta Conversão com Bootstrap e SASS

## 📌 Visão Geral do Projeto
O **Oceanis Cruises** é uma Landing Page responsiva e de alta conversão desenvolvida para o setor de turismo marítimo de luxo. O objetivo central do projeto foi aplicar e consolidar conceitos avançados de web design responsivo, gerenciamento de layouts modulares, estilização avançada com pré-processadores e otimização de performance front-end para captação de leads.

Projeto prático desenvolvido durante a formação especializada em Desenvolvimento Front-End da **OneBitCode**.

---

## 🛠️ Tecnologias, Frameworks e Ferramental
* **HTML5 Semântico:** Estruturação otimizada para motores de busca (SEO) e acessibilidade web.
* **Bootstrap 5:** Uso extensivo do Grid System para total responsividade (Mobile First), além de componentes nativos de componentes utilitários (cards e carrosséis).
* **SASS (Syntactically Awesome Stylesheets):** Organização profissional da folha de estilos através de arquivos parciais, aninhamentos e controle dinâmico de variáveis.
* **Técnicas de Design Visceral:** Implementação de máscaras de contraste (`linear-gradient`) acopladas diretamente às propriedades de `background-image` para assegurar o alinhamento de cores e acessibilidade textual.
* **Otimização de Ativos:** Configuração de carregamento de imagens no formato de última geração `.webp` para maximizar a velocidade de carregamento (Web Performance).

---

## 📂 Organização Estrutural do Repositório
* `images/`: Banco de ativos visuais otimizados no formato `.webp`.
* `scss/`: Código-fonte SASS com os arquivos parciais de estilo modular.
* `css/`: Arquivos CSS finais compilados e minificados para o navegador.
* `index.html`: Arquivo principal e ponto de entrada da aplicação semântica.
* `README.md`: Documentação técnica e executiva do projeto.
